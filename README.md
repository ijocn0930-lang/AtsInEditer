# ATS Plugin INI Editor

ATS シミュレータ用プラグインの INI 設定ファイルを安全かつ簡単に編集するための専用 GUI エディタです。

## 🌟 主な機能・特徴

- **文字コード自動判別 (UTF-8 / Shift-JIS)**: 開いたファイルの文字コード(UTF-8 BOMあり・なし / Shift-JIS)と改行をそのまま保って保存します。
- **コメントを消さない保存**: 変更した「値」の部分だけを書き換えます。行末の `; コメント` や他のセクション、コメント行はそのまま残ります。何も変えずに保存した場合、ファイルは変わりません。
- **「その他の設定」タブ**: パラメーター一覧表 (`ATS_ini_params.csv`) を読み込み、全パラメーターの入力欄を自動で作ります。
  - グループ(車両 / ATC / TASC / ATO / ホームドア / 計器 1〜8 など)ごとに見出しを付けて表示
  - 種類に合わせた入力欄: 数字(int/float)、チェック(bool)、選択(enum)、文字(list/special)
  - マウスを乗せると、セクション名・範囲・既定値・説明を表示
  - 英語表示に切り替えると、説明文とツールチップも英語になります(一覧表の `description_en` 列)
  - INI に書かれていない項目は既定値を表示。既定値のままの項目は保存時に書き足しません
  - 青い見出しをクリックすると、そのグループを折り畳み/展開できます(▼ 開いている / ▶ 閉じている)
  - タブの上の「すべて折り畳む」「すべて展開」ボタンで、全グループをまとめて切り替えられます
  - 計器 (Gauge1〜8) は「計器」の見出しの下に「計器 1」〜「計器 8」の小見出しでまとまっています。「計器」をクリックすると 8 つまとめて折り畳めます
  - 「車両」の `TascEnable` / `AtoEnable` のチェックを外すと、TASC / ATO グループの欄がグレーアウトします(値は保存されます)
- **保存前の範囲チェック**: 一覧表の最小値〜最大値の範囲外の値があると、一覧を表示して「このまま保存しますか？」と確認します(既定値と同じ値は対象外)。
- **保存前の組み合わせチェック**: 関係のある値どうしに矛盾があると、範囲外と一緒に表示します。
  - カンマ区切りの欄 (PressureRates / DriverPowerMap / ShoePositions) に数字でないものがないか
  - TASC の `ExtendedNotches` が `PressureRates` の個数以下か
  - ATO の `DriverPowerMap` の数字が `ExtendedPowerNotches` 以下か
  - 計器・架線電圧・制御電圧の `Min` が `Max` より小さいか
- **新規作成**: すべての値を一覧表の既定値に戻し、全項目を書いた新しい INI ファイル(UTF-8)を作ります。
- **ファイル排他制御 (FileShare.Read)**: エディタで開いている間、メモ帳等による他プロセスからの誤上書きや不整合を防止（ATS 本体からの参照・読み込みは許可）。
- **[ATC] セクション＆パラメータ制御**:
  - `ATCFail` (故障有効/無効) と UI 連動（入力欄の自動グレーアウト）
  - `FailParameter` (故障率) の範囲チェック＆自動補正 (0.0000001% 未満の自動リセット)
- **[VehicleSpec] セクション＆パラメータ制御**:
  - `MaxBrake` 車両ごとのブレーキ段数の設定
  - `AtcType` ATCタイプの設定。WS-ATCとCS-ATCの両方とWS-ATCだけとCS-ATCだけに制限することができます。選択肢は「0: WS-ATCのみ / 1: CS-ATCのみ / 2: 両方」のように名前付きで表示されます(保存される値は 0/1/2)。
- **[LineSpec] セクション＆パラメータ制御**:
  - `DefaultLine` 車両のデフォルトの号線に設定します。
  - `MinLine` 最低号線
  - `MaxLine` 最高号線
  - 号線は 1〜9 の範囲で設定できます(MaxLine の既定値は 9)。
  - 号線の欄の右に路線名が表示されます(1 御堂筋線 / 2 谷町線 / 3 四つ橋線 / 4 中央線 / 5 千日前線 / 6 堺筋線 / 7 長堀鶴見緑地線 / 8 今里筋線 / 9 北大阪急行)。
    - 中央線: 近鉄モードは中央線のみです。
    - 堺筋線: 阪急ATSと互換性がありません。

- **タイトルバーにファイル名を表示**: 「アプリ名 - ファイル名」の形で表示します。保存していない変更があるときは、ファイル名の前に `*` が付きます。
- **ウィンドウの大きさを変えられる**: 端をドラッグしたり最大化したりできます(起動時の大きさより小さくはできません)。「その他の設定」タブは広げたぶんだけ多くの行が見えます。
- **ウィンドウの位置と大きさを記憶**: 閉じたときの位置・大きさ (最大化も) で次回開きます。設定は `%LocalAppData%\AtsInEditer\settings.ini` に保存され、このファイルを消すと最初の状態に戻ります。
- **多言語対応 (日本語 / 英語)**: ワンクリックで UI やバルーンチップの言語を切り替え可能。選んだ言語は記憶され、次回もその言語で起動します。
- **堅牢なエラーハンドリング & WMI ログ記録**: 起動環境チェック失敗時は `Erroroutput.log` に詳細なシステム診断ログを出力。
- **クラッシュログ出力**:アプリケーションが例外スローしたらクラッシュログを出力します。

## 🖥 動作環境

- **OS**: Windows 11 24H2 (Build 26100) 以降 (64-bit 専用)
- **アーキテクチャ**: x64

## 🚀 使い方

1. `AtsInEditor.exe` を実行します。起動直後は、すべての値が一覧表の既定値になっています。
2. [ファイル] ＞ [開く] から対象の `ATS.ini` を読み込みます。(※`desktop.ini` ファイルまたは上記のセクションとキーがないファイルは無効です。)
3. 「基本設定」タブ・「その他の設定」タブで必要なパラメータを変更し、[上書き保存] (Ctrl+S) を実行します。
   別の名前で残したいときは [名前を付けて保存] (Ctrl+Shift+S) を使います(元のファイルのコメントなどは引き継がれます)。
4. 新しく作る場合は [ファイル] ＞ [新規作成] を使います(既定値で全項目が書かれます)。

## ⚠️ 注意事項
INIファイルが使用中であったり、アクセスが拒否される場合は、別のプロセスを終了してください。  
最低号線と最大号線が大きすぎるか小さすぎる、最低号線が最高号線を超えることはできません。  
間違った値が指定されているファイルを読み込んだ場合は初期値がセットされます。  
「その他の設定」タブを使うには、exe と同じフォルダに `ATS_ini_params.csv` が必要です(ビルド時に、プロジェクト内の `AtsInEditer\ATS_ini_params.csv` が自動でコピーされます)。  
パラメーター一覧表を直したときは、プロジェクト内の `AtsInEditer\ATS_ini_params.csv` も同じ内容にしてください。  
「その他の設定」タブでは、数字の欄や選択欄の上でマウスホイールを回すと、値は変わらずページがスクロールします。値の変更は ▲▼ ボタン・キーボード・直接入力で行ってください。
